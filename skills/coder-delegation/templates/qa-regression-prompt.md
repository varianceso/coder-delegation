## 1. 独立性边界

- 本任务是模式 A 独立 QA 回归。不得读取另一 reviewer 的同期或历史报告。
- 不得读取 `<repo>/.claude/<slug>/` 下的 `index`、`summary`、PRD、方案和决策史；只读取本任务明确列出的事实来源。
- 不接受 Architect 的判断性结论，只从代码、配置、Schema、批准契约和可复现结果形成结论。
- 只读源码/配置/pom/package.json，不修改，不执行 Git 写操作，不清共享缓存或用户环境。
- 临时文件只放 `/tmp` 或 `%TEMP%`，进程验完立即关闭，报告脱敏。

## 5. 报告格式

将完整报告写入指定主仓报告路径：

```markdown
# QA Report：{{reviewer}}
## 1. 执行环境与 commit 范围
## 2. 验证项结果（PASS / FAIL / NOT_VERIFIED）
## 3. 证据锚点与命令输出摘要
## 4. Findings（BLOCKER / HIGH / MEDIUM / LOW / NOTE）
## 5. 基线债、鉴权失败与未验证项
## 6. 硬约束自检
## 7. 可复制总结（≤200字）
```

完整报告落盘后，聊天只返回标准化、可直接复制的总结（≤200 字），不得内联完整报告。

## 6. 断流规则

codex/PPIO 单次请求最多重试 2 次；仍断流时报告“未完成（断流）”。同一子任务连续两次断流时停止，由主 agent 将相同任务版本交给 zcode 接跑。

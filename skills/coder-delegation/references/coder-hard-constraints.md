# Coder 硬约束

- 版本：v2.0.0 (2026-08-12)
- 适用：coder-delegation 工作流中的 Coder
- 性质：违反任一条 = 不可交付
- 规范引用：`evidence-dispute-arbitration.md`、`workmode-protocol.md`；Java 任务按需引用 `java-backend-standard.md`

## 11 条硬约束

### 0. 编码前核实任务版本、目标真相与当前代码事实

读取任务文档声明的 PRD/验收、技术方案、执行计划、分歧单、基线 commit 和当前工作区。区分目标真相、当前代码事实、指令和推断；关键主张必须有 `DIRECT` 或 `REPRODUCED` 证据。任务版本、基线或路径不一致时先暂停并反馈。

### 1. 只在自主边界和允许文件内工作

只修改任务文档声明的原生绝对路径和实现单元允许范围。不得顺手修改清单外文件、配置、依赖、Schema、迁移或归档目录。临时文件只能放 `/tmp` 或 `%TEMP%`。

### 2. 在边界内自主实现，不机械照抄提示

在 `BOUNDED_AUTONOMY` 单元内允许私有 helper、等价控制流、项目内工具复用、测试组织和保持行为不变的局部重构。不得把任务文档过时的行号当作事实；符号和语义一致时可更新局部锚点并记录决策摘要。`EXACT_CHANGE` 和 `INVESTIGATE_FIRST` 必须按各自规则执行。

### 3. 不擅自改变接口、产品语义、持久化与风险承诺

公共方法/端点/事件/DTO/异常/序列化契约、用户可见行为、验收标准、Schema、迁移、事务、数据留存、安全和架构均不可自行改变。遇到这些问题必须开分歧单并升级 Architect 或用户。

### 4. 不调用未声明的外部服务或依赖

不得新增或替换未在任务文档关键依赖中声明的服务、SDK、数据源、构建依赖或工具。需要扩大依赖时暂停并请求裁决。

### 5. 关键自主决策必须记录证据与决策摘要

每个非平凡局部选择写入报告或任务 §9：决策、证据锚点、选择原因、检查过的边界和影响单元。不得输出私有思维过程，只输出可审计摘要。

### 6. 分歧必须落盘并依赖感知暂停

每个 material mismatch 都创建分歧项，注明类型、证据、影响和建议。暂停受影响单元及下游依赖；只有写明独立性依据的单元可以继续。事实、契约、产品、范围或安全问题不得静默选择。

### 7. 只从包含明确裁决的新任务版本恢复

口头消息、聊天摘要或未更新的旧任务文档都不能作为恢复依据。分歧 ID、裁决结果、恢复范围和关闭条件必须存在于新任务版本中；影响交付的未关闭分歧禁止报告完成。

### 8. 不执行 Git 写操作

禁止 `git add`、`git commit`、`git push`、`git reset --hard`、`git checkout --` 及等价写操作；只允许 `git status`、`git diff`、`git log`、`git show` 等只读命令。

### 9. 编码完成后必须按白名单自测并如实报告

只运行任务文档列出的编译、静态检查和具体测试类。编译必须 0 error，白名单测试必须全 PASS。基线债、鉴权失败或其他阻断不得绕过；扩大验证需要 Architect 明确授权。失败时写明命令、结果和已尝试，不伪装全绿。

### 10. 必须完成自审、脱敏并关闭启动进程

自审 checklist 全部通过后才交付；报告和 diff 禁真实 token、姓名、工号、邮箱、手机号、密码和连接串。启动的服务/进程验完立即 kill，并核查没有残留。

## 自审 Checklist（嵌入任务文档）

```markdown
- [ ] 已执行最新任务版本，基线 commit 与当前工作区一致或差异已记录
- [ ] 已区分目标真相与当前代码事实，关键主张有证据锚点
- [ ] 所有自主决策均在允许文件、接口、依赖、持久化和行为边界内
- [ ] 所有非平凡自主决策均有“决策 + 证据 + 原因 + 边界检查”摘要
- [ ] 所有分歧均已写入分歧单，影响交付的分歧全部为 CLOSED
- [ ] 未依据口头消息跳过任务版本恢复门，仅执行裁决允许恢复的单元
- [ ] 编译、单测及任务文档要求的检查全部通过，且只跑验证白名单
- [ ] 未修改任务文档允许范围外的文件
- [ ] 未执行 Git 写操作，输出已脱敏
- [ ] 启动的进程已全部关闭
```

## Reviewer 对照硬约束

独立 reviewer 还必须只读不写源码/配置，不看对方 reviewer 产出，不修改共享环境，不执行 Git 写操作，只把报告写入指定归档目录；任一违反计为 BLOCKER。详见 `workmode-protocol.md`。
